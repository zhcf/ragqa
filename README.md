# PDF 手册问答（本地 llama.cpp）

一个**完全离线**的 PDF 手册问答桌面程序。

它在手册里检索出与问题最相关的段落，交给本机的 llama.cpp 小模型组织成答案，
然后自动翻到原文那一页并标黄。全程不联网、不上传任何文档。

- 生成模型：Qwen3.5 系列（2B / 4B / 9B，GGUF Q4_K_M 量化，跑在 llama.cpp 上），默认 4B
- 向量模型：bge-small-zh-v1.5（中文检索）
- 界面：PySide6，Windows 桌面

---

## 一、快速开始

**源码运行**：双击同目录下的 `start.bat`，等状态栏变成绿色的「就绪」即可提问。

**打包版运行**：双击 `ragqa.exe`，首次启动约 10～25 秒（要加载向量模型和生成模型），之后 4B 每次提问 4～8 秒、2B 约 2～3 秒。

启动过程分两步，状态栏会依次显示：

```
● 正在加载向量模型并建立索引…
● 正在启动 llama-server（Qwen3.5-4B）…
● 就绪 · Qwen3.5-4B · 240 块 / 106 页
```

第一次打开（还没有选过手册）时 PDF 区是空的，状态栏提示「请点「打开 PDF…」选择一本手册」，
生成模型也已经启动好——选完手册建完索引就能直接提问，不用重启。

关闭窗口就会一并结束后台的 `llama-server` 进程。如果程序异常退出留下了残留进程，
双击 `stop.bat` 清理（打包版同名脚本）。

## 二、界面怎么用

左边是提问区，右边是 PDF 原文。

| 位置 | 作用 |
|---|---|
| 顶部「生成模型」下拉框 | 显示当前模型名（只有一个时固定），见第三节 |
| 顶部「打开 PDF…」 | 换一本要问答的手册，选完自动重建索引，见第四节 |
| 顶部「重建索引」 | 手动重新切块建索引（改过切块参数时用） |
| 顶部状态栏 | 显示模型、块数、页数、上次问答耗时 |
| 左上输入框 + 「提问」 | 支持多行：**Enter 提交，Shift+Enter 换行**；也可点「提问」 |
| 答案区 | 模型生成的回答；法规类会在结论后附「相关规定」列表（每条带页码），普通文档末行是「依据：第 N 页」，点蓝字可跳转 |
| 「检索依据」列表 | 命中的 4 个原文段落及相似度，**点任意一条**会跳到那一页并高亮 |
| 右侧 PDF | **滚动即翻页**，拖右侧滚动条或转滚轮可连续浏览全部页面 |
| PDF 顶部 | 当前手册名、「当前页 / 总页数」随滚动实时更新，右边是「缩小 / 放大」 |

**看答案的推荐姿势**：先读答案，再点「依据」里的段落核对原文。
黄色高亮的是这段资料里跟问题最相关的内容：普通文档标 1～2 句，带「第 X 条」的法规
标注整条——如果高亮的位置和问题无关，说明是检索没找准，换个说法再问通常能改善。

## 三、生成模型

预装了三个模型，顶部下拉框随时切换，选择会记进 `settings.ini`，下次启动沿用：

| 模型 | Q4_K_M 大小 | 本机单问耗时 | 说明 |
|---|---|---|---|
| Qwen3.5-2B | 1.19 GB | 1.5～3.5 秒 | 最快；能念准单条条文，但归纳、判断“资料里到底有没有”较弱 |
| **Qwen3.5-4B（默认）** | 2.55 GB | 4～8 秒 | 多句归纳、指出“法条只写了定期、没给具体周期”这类判断明显更稳 |
| Qwen3.5-9B | 5.29 GB | 9～14 秒 | 最稳健、答得最完整，等待也最久 |

Qwen3.5 的 chat template 默认会先生成思考过程，在 CPU 上会把 300 token 的预算全花在思考里、
正文一个字都没有（表现为“全空”“超时”）。程序调接口时统一带
`chat_template_kwargs: {"enable_thinking": false}` 直接出答案；Qwen2.5 等旧模板没有这个变量，传了也不受影响。

启动取值顺序是「`settings.ini` 的记录 → `DEFAULT_MODEL` → 任何一个 GGUF 还在的模型」，
每级都校验文件是否存在，所以删掉某个 `.gguf` 不会导致启动报错，下拉框里那一项会显示「（未下载）」并置灰。

## 四、换一本 PDF

工具栏「打开 PDF…」可以直接选任意 PDF，**选完自动重建索引**，不用改名、不用重启：

1. 点「打开 PDF…」，在弹出的对话框里选一本 PDF；
2. 状态栏显示「正在为「xxx.pdf」建索引…」，几秒后变成新的「块数 / 页数」；
3. 右上角会显示当前手册的文件名，左侧问答区和依据列表自动清空，接着提问即可。

选择会被记住：路径写进 `settings.ini` 的 `pdf=`，下次启动直接读这本；
没有记录、或记录的文件被挪走删掉时，启动回到空白的 PDF 区，不会启动报错。

程序文件夹里的 `userguide.pdf` 只是示例手册，不会自动打开；想问答它就点「打开 PDF…」选它。

几点提醒：

- 必须是**文本型 PDF**。扫描件（整页是图片）提取不到文字，会提示「PDF 里没有可用文本，可能是扫描版」。
- 中文手册效果最好；普通文档切块按 400 字、重叠 80 字；全文有多条「第 X 条」的法规类文档会自动改成一条一块（超长条款再按 400 字拆），检索和标黄都按整条工作。
- 页面上显示的页码是**PDF 物理页序**，和手册自己印的页码可能差几页（比如印着第 74 页、物理是第 80 页）。
- 索引需要几秒到几十秒（106 页约 6 秒），页数越多越久；索引在内存里，不落地成文件，换文档没有缓存要清理。

## 五、新增一个模型

模型的清单集中在 `config.py`，加一项就能出现在下拉框里：

1. 把 `.gguf` 文件放进 `model/gguf/`（推荐 Q4_K_M 量化）；
2. 打开 `config.py`，在 `MODELS` 里加一条：

```python
MODELS = {
    # 新增一条，key 自己取，label 是下拉框显示的文字
    "qwen3.5-4b": {
        "label": "Qwen3.5-4B",
        "gguf": GGUF_DIR / "Qwen3.5-4B-Q4_K_M.gguf",
    },
}
```

3. 重启程序，下拉框里就有了。

不是 Qwen 系列的新模型也没关系：只要 gguf 能被 `llama-server` 直接加载就能用；
chat template 来自 GGUF 内置的模板，程序侧只额外传了 `enable_thinking=false` 这一个开关
（模板里没有这个变量的模型会忽略它）。

想改默认模型，把 `DEFAULT_MODEL` 改成对应的 key。
想调整生成长度、检索条数、切块大小，也在 `config.py` 里
（`MAX_NEW_TOKENS`、`TOP_K`、`CHUNK_SIZE`、`CHUNK_OVERLAP`）。

## 六、常见问题

**启动慢，卡在「正在加载向量模型并建立索引…」**
首次加载要读 183 MB 的向量模型并编码整本手册，106 页约 7 秒，属正常。
页数多的文档会更久，状态栏变绿即完成。

**提示「索引失败」或块数为 0**
PDF 可能没有文字层（扫描件）。用阅读器选中文字试试，选不中就是图片版，需要先做 OCR。

**提示「生成模型启动失败」**
多为 `llama/` 目录缺失或被安全软件拦截。程序会自动重试一次；
仍失败时看同目录的 `llama-server.log`，里面是 llama.cpp 自己的输出。

**端口被占用**
默认用 `127.0.0.1:18321`。如果被别的程序占了，程序会自动换一个空闲端口，无需干预。

**答案不完整 / 答非所问**
先看「检索依据」里的段落对不对。检索没命中就换关键词（用手册里的原词）
再问一次；检索命中了但答案仍残缺，把 `MAX_NEW_TOKENS` 调大试试。

**能不能删掉 `model/` 里的某个模型？**
能。删掉对应的 `.gguf`，下拉框里那项会显示「（未下载）」并被置灰，另一个模型照常可用。

## 七、目录结构

**打包版**（`dist/ragqa/`，可以直接整个目录拷给别人）：

```
ragqa/
├─ ragqa.exe            双击运行
├─ _internal/           Python 运行库（PySide6 / torch 等），不要删改
├─ userguide.pdf        示例手册，点「打开 PDF…」可选它
├─ llama/               llama.cpp 预编译二进制
│   └─ llama-server.exe
├─ model/
│   ├─ bge-small-zh-v1.5/   中文向量模型
│   └─ gguf/                生成模型（2B/4B/9B，共约 9 GB，不用的可删）
└─ ragqa使用手册.html 面向使用者的说明（不含源码内容）
```

运行后还会在同目录生成 `app.log`、`llama-server.log`、`.app.pid`、`settings.ini`。

**源码版**（项目根目录，比打包版多出这些开发文件）：

```
rag/
├─ start.bat / stop.bat     一键启动、一键停止
├─ config.py                模型清单、路径、检索与生成参数
├─ rag_core.py              解析 PDF、切块、检索、生成、定位高亮
├─ llama_client.py          llama-server 进程管理与接口调用
├─ desktop.py               桌面界面与交互
├─ pdf_view.py              连续滚动的 PDF 阅读视图
├─ entry.py                 打包入口，只在生成 exe 时用
├─ build.py                 打包脚本，重新生成 dist
└─ requirements.txt         Python 依赖
```

两种形态共用同一份 `llama/`、`model/`、`userguide.pdf`，行为完全一致。
