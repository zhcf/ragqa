ragqa 使用手册

ragqa 是一个完全离线的 PDF 手册问答工具：把 PDF 手册放进去，用中文提问， 它会在手册里找出相关段落，整理成步骤回答你，并把原文那一页高亮出来。

全程不联网，你的问题和文档都不会离开这台电脑。

本手册只讲怎么使用这个程序：启动、提问、看答案、翻阅原文、换手册。

一、第一次打开

  1. 把 ragqa 整个文件夹拷到电脑上。不要只拷 ragqa.exe—— 它旁边的 _internal、llama、model 都是运行必需的。
  2. 双击 ragqa.exe。第一次打开时右边 PDF 区是空的，状态栏提示「请点「打开 PDF…」选择一本手册」—— 点工具栏「打开 PDF…」，选一本自己的 PDF（也可以选文件夹里的示例手册 userguide.pdf）。
  3. 状态栏先显示「正在启动 llama-server…」，选完手册后显示「正在为「xxx.pdf」建索引…」， 最后变成绿色的「就绪」。第一次总共约 10～25 秒。
  4. 在左上输入框里打字，按 Enter 或点「提问」。 第一次问答还要等模型预热，约 8～10 秒；之后每次 4～8 秒（默认 4B 模型）。

想从桌面启动，就给 ragqa.exe 建一个快捷方式。 快捷方式只是指路，其他文件仍然留在原文件夹里，不能挪走。

第一次打开可能会被 Windows 或杀毒软件拦一下，因为这个 exe 没有数字签名。 选择「仍要运行」即可，程序不联网，可以放心。

二、界面说明

左边提问、看答案；右边是手册原文，滚动就能翻阅。

位置作用

「提问」按钮和按 Enter 一样。答案生成期间按钮会变灰，此时不能连点
答案区模型生成的回答。法规类手册会在结论后列出「相关规定」（每条带页码）；普通文档最后一行是「依据：第 N 页」
「检索依据」从手册里找到的 4 段原文和相似度，点任意一条直接跳到那一页
右侧 PDF滚动即翻页，转滚轮或拖右侧滚动条都能连续看
PDF 顶部当前手册名和「当前页 / 总页数」，随手滚动实时更新；右边是「缩小 / 放大」
顶部「生成模型」显示当前加载的模型名称，见第五节
顶部「打开 PDF…」换一本要问的手册，选完自动重建索引，见第六节
顶部状态栏当前模型、手册块数、总页数、上次问答耗时

三、怎么问才答得准

它不是一个闲聊的机器人，而是照着手册里的原话回答问题的。所以问法有讲究：

  • 用手册里的词。问「怎么给作业添加标签」比问「我想给任务分类」更容易命中。
  • 一次问一件事。「怎么新建作业，还有怎么删除」拆成两次问，答案更完整。
  • 问操作步骤效果最好，比如「如何提交作业」「日志在哪里查看」「怎么配置邮箱通知」。
  • 问手册里没有的内容，它会回答「资料中没有找到相关内容」——这是正常表现，不是故障。

答案下面的「检索依据」是它实际读过的段落。养成核对的习惯： 点开依据，看看黄底高亮那几行是不是你问的内容。对不上说明检索偏了，换个说法再问一次。

四、翻阅手册原文

右边的 PDF 是连续滚动的，没有上一页 / 下一页按钮：

  • 转鼠标滚轮或拖右侧滚动条，一路往下翻，可以连续浏览全部页面。
  • 顶部页码跟着滚动实时变化，例如「80 / 106」表示当前在第 80 页、共 106 页。
  • 页面太小或太大，点右上角「缩小 / 放大」，每点一次 15%。
  • 在「检索依据」里点某一条，或在答案里点「第 N 页」，会自动跳过去并把命中的句子黄色高亮。

只涂跟问题最相关的内容：普通文档一两句，带「第 X 条」的法规标注整条，不会把整页标满；如果涂的位置和问题无关，说明检索没找准，换个说法再问。

关于页码：这里显示的是 PDF 的物理页序。手册自己印的页码可能和它对不上 （比如印着「第 74 页」，软件里是第 80 页，因为前面有封面、目录）。以软件的页码为准。

五、关于模型

程序预装了三个生成模型，顶部「生成模型」下拉框随时切换，选过的模型下次启动自动沿用：

模型大小单问耗时说明
Qwen3.5-2B1.19 GB1.5～3.5 秒最快；能把单条条文念准，但归纳、判断「资料里到底有没有」的能力较弱
Qwen3.5-4B（默认）2.55 GB4～8 秒归纳多句、判断「法条只写了定期、没给具体周期」这类结论明显更稳
Qwen3.5-9B5.29 GB9～14 秒最稳健、答得最完整，等待也最久

默认用 4B：比 2B 多等几秒，但答案会指出「资料里没有直接写」，而不是硬编一段。 对速度要求高就切 2B，对准确度要求高就切 9B。

如果下拉框里某项后面出现「（未下载）」，说明 model\gguf\ 里对应的模型文件被删了， 把文件补回去再重启即可；其他模型不受影响。

六、换成你自己的 PDF 手册

点工具栏的「打开 PDF…」，选中你要问的那本 PDF 就行—— 不必改名，也不必挪动原文件：

  1. 点「打开 PDF…」，在对话框里选一本 PDF。
  2. 状态栏变成「正在为「xxx.pdf」建索引…」，几秒后恢复成绿色的「就绪」。
  3. PDF 区顶部会显示新手册的文件名，页码从 1 / 新页数 开始，左边的答案和依据自动清空。

程序会记住这本手册：下次打开还是它。想换回去，再点一次「打开 PDF…」即可； 如果记着的那本被删了或挪走了，下次启动 PDF 区会回到空白，再选一本就行，不会打不开。

页数越多建索引越久（106 页约 6～7 秒），期间提问按钮是灰的，等它变绿再问。 索引只在运行期间存在内存里，不写文件，所以不需要清理任何缓存。

几点必须注意：

  • 只能是文字版 PDF。整页是扫描图片的 PDF 提取不到文字，会提示「PDF 里没有可用文本」。 判断方法：用阅读器打开，鼠标能选中文字就是文字版；扫描件需要先做 OCR 转成文字版。
  • 中文文档效果最好；英文文档也能用，但用中文提问命中率会下降。
  • 适合说明书、操作手册这类结构化文档，单本 100～500 页最舒服。
  • 换成别处的文件后，原文件不要随手删——程序记的是它的路径，删了下次启动 PDF 区就空了。

七、常见问题

双击 exe 没反应，或者窗口一闪就没了
先确认文件夹是完整的：ragqa.exe 旁边必须有 _internal、llama、model。 只拷一个 exe 是跑不起来的。还不行就看看文件夹里有没有 startup-error.log，里面记了失败原因。
一直卡在「正在加载向量模型并建立索引…」
首次启动要读向量模型并把整本手册编码一遍，106 页约 7 秒，属正常。 如果超过两三分钟没动静，多半是 PDF 太大或没有文字层。
提示「索引失败」，或者状态栏块数是 0
PDF 没有文字层（扫描件），见第六节。
提示「生成模型启动失败」
多半是 llama 文件夹缺失，或被安全软件拦截。程序会自动重试一次； 仍然失败时，看文件夹里的 llama-server.log。
杀毒软件报毒 / 提示风险
自打包的程序容易被误报。整个程序不联网，所有文件都在本地，可以加入信任。
答案总是「资料中没有找到相关内容」
先看「检索依据」是不是空的。空的话是问法和手册用词差太远，换成手册里的原话再试； 如果是换了 PDF 之后变成这样，先检查新 PDF 是不是扫描件。
检索很准，但答案只给了一半
说明这个问题本身太大，拆小一次问一件；也可以把问法换成手册里的原词再试一次。
同时开两个窗口
不建议。第二个实例会连到同一个后台服务，容易互相干扰。
怎么卸载
直接删掉整个文件夹就行，不写注册表、不留系统文件。 运行时会生成 app.log、llama-server.log、.app.pid、settings.ini 四个文件，删文件夹时一并清掉。

八、文件夹里都是什么

ragqa\ 程序主目录，整个文件夹一起拷
├─ ragqa.exe 双击运行
├─ ragqa使用手册.html 就是本说明
├─ userguide.pdf 示例手册（可选），用顶部「打开 PDF…」选它或换成别处的文件
├─ _internal\ 程序运行库，不要删、不要改名
├─ llama\ llama.cpp 推理引擎（llama-server.exe 和一批 dll）
└─ model\ 模型目录
├─ bge-small-zh-v1.5\ 中文向量模型，负责找相关段落
└─ gguf\ 生成模型目录
└─ *.gguf 生成模型（Qwen3.5 2B / 4B / 9B，删掉不用的能省空间）

运行后还会在同目录生成四个文件：

  • app.log：程序日志，出问题时最先看这个；
  • llama-server.log：推理引擎自己的日志；
  • .app.pid：记录正在运行的实例，正常退出会自动删除；
  • settings.ini：记住上次用的模型和手册，删掉就恢复成第一次打开的样子（PDF 区空白）。

可以删的：上面那几个日志和记录文件。
不能删的：_internal\、llama\、model\bge-small-zh-v1.5\。

整个文件夹约 2 GB，大头是模型和运行库。拷给别人时要整个文件夹一起拷，别只拷 exe。
